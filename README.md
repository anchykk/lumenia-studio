# Lumenia — сайт фотостудії у Львові

Навчальний проєкт курсу «Веб-розробка» (DOTS Academy). Адаптивний сайт фотостудії: оренда залів, послуги, школа фотографії, календар, ціни та форма бронювання.

**Живий сайт:** https://USERNAME.github.io/lumenia-studio/

> Замініть USERNAME на своє ім'я користувача GitHub.

## Що є на сайті

- Адаптивна верстка від 320 до 1920 px (flex, медіа-запити)
- Бургер-меню без JavaScript (на CSS)
- Секції з фоновим зображенням і відео
- Форма бронювання з перевіркою полів (`required`, `pattern`, `min`, `max`) та таблиця цін
- Система UI-компонентів: кнопки `.btn`, картки `.card`, блок цін із трьох пакетів
- CSS-анімації: плавні переходи, підйом карток, поява першого екрана на `@keyframes`
- Налаштування `prefers-reduced-motion` для користувачів, яким рух шкодить

## Технології

HTML5, CSS3, Flexbox, CSS-змінні, медіа-запити. Без фреймворків і бібліотек. Єдиний JavaScript — короткий скрипт, що підставляє вибраний пакет у форму.
